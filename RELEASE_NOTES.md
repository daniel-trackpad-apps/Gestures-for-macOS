# Gestures for macOS 1.0

First public release.

## What it does
Gestures for macOS listens to your trackpad and runs a different action depending on which app is in front. For example, a two-finger swipe can switch tabs in Safari and go back a folder in Finder.

## Features
- Gestures: swipes (2/3/4 fingers), pinch, rotate, taps and holds, swipes along the trackpad edge, corner taps, and your own recorded custom gestures
- Actions: common shortcuts (Back, Forward, Close Window, New Tab, and more), system actions (volume, brightness, play/pause, screenshot, switch desktops), items from the active app's menus, and recorded keyboard shortcuts
- Set gestures for all apps, or for a specific app (app settings take priority)
- Warns you when a gesture conflicts with a built-in macOS gesture
- Diagnostic log

## Requirements
- macOS 14 or later
- A trackpad (Magic Mouse is not supported)
- Accessibility permission (Input Monitoring is optional)

## Note: the app is not signed
This app is not signed or notarized by Apple, so macOS will warn you the first time you open it. To open it anyway: System Settings > Privacy & Security > scroll down and click "Open Anyway".
